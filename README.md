# Gestor de Procesos y Memoria

Simulador de gestión de procesos en C++.

## Descripción

Programa que simula la gestión de procesos de un sistema operativo usando listas enlazadas, colas y pilas.

## Integrantes

- Parte 1: ENRIQUE RICCE, ANGELA ARIANA
- Parte 2: MARQUEZ ENRIQUEZ, JAVIER EDUARDO
- Parte 3: URIBE OLIVA, ELIAS XAVIER
- Parte 4: ORELLANA CONDEZO, CESAR DANIEL 

## Archivos

- `parte1_estructuras.cpp` - Estructuras y archivos
- `parte2_gestion_procesos.cpp` - Gestión de procesos
- `parte3_cola_cpu.cpp` - Cola y ordenamiento
- `parte4_main.cpp` - Main y memoria

## Compilar
```bash
g++ parte1_estructuras.cpp parte2_gestion_procesos.cpp parte3_cola_cpu.cpp parte4_main.cpp -o gestor
```

## Ejecutar
```bash
./gestor
```

## Funciones principales

- Insertar, listar, eliminar y buscar procesos
- Modificar prioridad
- Ordenar por prioridad
- Cola de CPU
- Gestión de memoria (push/pop)
